ODOO ↔ TIENDANUBE
Official Odoo-Tiendanube Integration to Centralize Your eCommerce
Automatically Sync Products, Inventory, Orders and Customers

The Odoo-Tiendanube application is an integration connector that acts as a bridge between your Tiendanube online store and your Odoo ERP system. It is a tool designed to automate data and process management between both platforms, eliminating manual tasks and reducing operational errors.

Integrate your online store with your management system and keep products, inventory, orders and customers automatically synchronized between Tiendanube and Odoo. This integration prioritizes security (HTTPS and OAuth 2.0) and offers a guided setup so you can get started without advanced technical knowledge.

Odoo-Tiendanube is a connector that integrates Tiendanube with Odoo ERP to centralize your ecommerce operation: catalog, stock, prices, orders, customers and invoicing are managed from a single place, reducing manual tasks and errors.

Installation and Configuration Guide
Step 1: Prerequisites
  • Odoo version 17.0 or higher (Community or Enterprise)
  • Active Tiendanube account with admin panel access
  • Administrator permissions in Odoo
  • Base modules installed: Inventory, Sales, API Connector
Step 2: Module Installation
  1. Download Tiendanube modules from Odoo App Store
  2. Extract and place the folder in your Odoo addons_path
  3. Update the app list from the Applications menu
  4. Search for "Tiendanube" and install the main module
  5. Dependencies will be installed automatically
Step 3: Initial Configuration
  1. Go to API Connectors > Tiendanube
  2. Press the "Activate" button
  3. Enter your Tiendanube credentials (Store ID and Access Token)
  4. Configure the warehouses to be synchronized
  5. Define product categories to sync
Step 4: Webhook Activation
  1. Go to Webhooks/Automations
  2. Activate the "UPDATE STORE" webhook
  3. Verify that product, order, and customer webhooks are active
  4. Test the connection by syncing a test product
Step 5: First Synchronization
  1. Execute initial product sync from Odoo
  2. Verify products appear correctly in Tiendanube
  3. Place a test order in Tiendanube
  4. Confirm the order imports correctly into Odoo
  5. Configure cron jobs for automatic synchronization

Frequently Asked Questions
What Odoo versions are compatible?

The connector is compatible with Odoo 17.0 and higher, both Community and Enterprise versions. It also works on Odoo.sh and on-premises deployments.

Do I need technical knowledge to install it?

Not necessarily. The installation process is guided step by step. However, basic Odoo administration knowledge is recommended, or have Soltein support for initial implementation.

Is synchronization real-time?

Yes, thanks to Tiendanube webhooks, changes sync almost instantly. Additionally, there are configurable cron jobs for scheduled inventory and price synchronizations.

Does it work with multiple warehouses?

Yes, the connector supports managing multiple warehouses in both Odoo and Tiendanube, allowing you to map each Tiendanube warehouse to specific locations in Odoo.

What happens if there's a synchronization error?

The system has detailed error logs, automatic notifications, and intelligent retries. Additionally, each sync includes pre-validations to avoid overwriting important data.

Does it overwrite my existing data?

No. Every operation includes conflict validations and company scoping before writing to Odoo. You can configure which data syncs and which remains local.

Is it compatible with Tiendanube Plus?

Yes, the connector is compatible with all official Tiendanube plans, including Tiendanube Plus, custom storefronts, and middleware webhooks.

Does it include technical support?

Yes, Soltein offers email technical support during Mexico business hours (GMT-6). Professional support is also available for implementations, customizations, and continuous monitoring.

What is the cost of the integration?

Can I exclude products or categories from synchronization?

Yes, you can mark specific categories and attributes to exclude them from Tiendanube synchronization. This allows you to maintain exclusive products on each platform.
